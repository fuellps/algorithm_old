### 随机数

> 随机数生成
>
> Java: java.util.Random类对象中$nextXXX$方法。如nextInt(origin`inclusive`,bound`exclusive`)
>
> Python:random模块中的$randint(a,b)$ 生成[a,b]的随机数
>
> 
>
> C++：$srand(time(0))$;`先设置随机数种子.` $rand()$生成[0,RAND)MAX]之间的数  `依赖系统，不推荐使用`  可以参考 https://codeforces.com/blog/entry/61587
>
> 使用c++提供的random头文件，做法如下：
>
> 

```c++
// 用当前时间作为种子，保证每次运行不同
mt19937 rng(chrono::steady_clock::now().time_since_epoch().count());

mt19937 rng(time(0)); //j
int randint(int l, int r) {
    return uniform_int_distribution<int>(l, r)(rng);
}

double randdouble(double l, double r) {
    return uniform_real_distribution<double>(l, r)(rng);
}
```
