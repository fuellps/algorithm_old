### 选择排序

每一轮选出1个最小/最大值,循环n-1轮即可得到n-1个最小/最大值,此时数组有序.

```c++
//使数组非递减序
for(int i = 0;i + 1 < n; i++){
    int t = i;
    //找到最小值
    for(int j = i + 1; j < n; j++){
        if(nums[j] < nums[t]){ 
            t = j;
        }
    }
    swap(nums[t], nums[i]);
}
```

- **时间复杂度**: $O(n^2)$

### 冒泡排序

每一轮扫描,**交换相邻元素**最大/最小的元素,一轮交换就会使数组未排序的最末尾元素有序.执行n-1轮即可完成排序.

```c++
void bubbleSort(vector<int>& a){
    int n = a.size();
    for(int i = 0;i + 1< n;i++){//只需执行n-1次，就能使数组有序
        for(int j = 0;j + 1 < n -i; j++){
            if(nums[i] > nums[j]) swap(nums[i],nums[j]);//将前面n-i个数的最大值换到第n-i-1位置上面
        }
    }
}
```

- **时间复杂度**: $O(n^2)$

考虑优化的话,可以定义一个变量表示是否进行交换.如果一轮中没有交换即数组中已经有序了

```c++
//使数组成非递减序 
bool change = true;
int cnt = 0;
while(change){
    change = false;
    for(int i = 0;i + 1< n-cnt; i++){
        if(nums[i] > nums[i+1]){
            change = true;
            swap(nums[i], nums[i+1]);
        }
    }
    cnt++;
}
```

**时间复杂度**: $O(n^2)$

### 插入排序

遍历数组,对于位于下标i处,假设$\sum_{j = 0}^{i-1}nums[i](i > 0)$已经有序.

此时对于下标i处只需找到一个合适的位置插入即可.

```c++
//使数组非递减排序
for(int i = 1;i < n; i++){
    int t = nums[i];
    int j = i;
    //前1个数大于当前数,前一个数覆盖当前位置.
    for(;j > 0 &&  nums[j-1] > nums[j]; j--){
        nums[j] = nums[j-1];
    }
    //将t插入合适的位置
    nums[j] = t;
}
```

- **时间复杂度**: $O(n^2)$
