### 相关性质

#### XOR（Exclusive OR）

- 异或的本质是**不进位加法**
- $ x \oplus x = 0, 0 \oplus x = x$
- 区间[l,r]内两个数的最大异或和为 $2^{bitlen(l\oplus r)} -1$
- $a \oplus b \le a + b$

#### OR

- 或的数越多，结果越大。当 **a | b = a**时，说明a是b的超集

#### AND

- 与的数越多，结果越小。当 **a & b = a**时，说明a是b的子集

- 加法恒等式

$$
\begin{aligned}
&a + b = (a|b) +(a \& b) \\
&a + b = (a\oplus b) + 2(a\&b)  \qquad \because a|b = (a \oplus b) + (a \&b)
\end{aligned}
$$

> 例题:给定t组数字,判断是否存在两个非负整数p,q,满足x= p + q,y =p$\oplus$q.
>
> 满足条件输入"Yes”,不满足条件输出"No”
