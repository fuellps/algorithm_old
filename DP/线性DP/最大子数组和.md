### 思路

#### 动态规划

$$
\begin{aligned}
&对于子数组最大和,一般定义dfs(i)表示以i结尾的子数组最大和. \\
&分类讨论： \\
&选择和以i-1结尾的子数组拼起来形成新的子数组\\

&或者自己单独作为子数组，不和i-1结尾的子数组拼起来\\

&即dfs(i)= max(dfs(i-1),0)+nums[i]\\
\end{aligned}
$$

> 注意:这个状态方程只依赖于前一个状态,每个状态只会访问一次,因此不会由重复访问的情况.因此只需普通递归就行,不需要开记忆化数组.

```java
//递归:下面代码求整个数组的最大子数组和
int ans = Integer.MIN_VALUE; //整个数组的最大子数组和
//dfs(i)表示以i结尾的最大子段和。
int dfs(int i,int[] nums){
    if(i==0) return nums[0]; //或者 	if(i < 0) return 0; 
    int res = Math.max(dfs(i-1),0) + nums[i];
    ans = Math.max(ans, res);
    return res;
}

```

```java
//动态规划代码
int dp = new int[nums.length];
int ans = dp[0] = nums[0];
for(int i = 1;i < nums.length; i++){
    dp[i] = Math.max(dp[i-1],0) + nums[i];
```

>  空间优化:每个状态只依赖于前一个状态,因此只需一个变量来滚动更新即可.

```java
int ans,f0;
ans = f0 = nums[0];
for(int i = 1; i < nums.length; i++){
    f0 = Math.max(f0,0) + nums[i];
    ans = Math.max(ans,f0);
}
return ans;
```

#### 前缀和

$$
\begin{aligned}
&定义s[i]表示nums数组前i个数的元素和。特别的，规定s[0] = 0 \\
&则有\sum^{i}_{j=0}s[i+1] = s[i] + nums[i](nums数组下标从0开始) \\
&对于 \sum^{r}_{l=i}nums[i] = s[r+1] - s[l].(nums数组下标从0开始) \\
&想要让子数组和最大，可以枚举子数组右端点，同时维护前缀最小值。
\end{aligned}
$$

```c++
int get_submax(){
    int s = 0,mns = 0;
    ans = -0x3f3f3f3f;
    for(int i =0;i < n; i++){
        s += nums[i];
        ans = max(ans, s - mns);
        mns = min(mns,s);
    }
    return ans;
}
```
